스마트폰과 아두이노를 블루투스로 직접 연결합니다. 아두이노 Wi-Fi 접속은 필요하지 않습니다.

01 · 연결 상태장치 미연결
블루투스 연결 대기

휴대전화의 Bluetooth를 켠 뒤, Chrome(Android) 또는 Bluefy(iPhone)에서 연결 버튼을 눌러 주세요.

02 · 속도 설정PWM 명령값 · 실제 RPM 아님
설정 속도120 / 255
0 정지128 중간255 최대
03 · 방향 제어연결 필요

버튼을 누르고 있는 동안만 명령을 반복 전송합니다. 손을 떼면 정지 명령을 보냅니다.

현재 제공되는 아두이노 코드는 모터 출력 비활성화(시뮬레이션) 상태입니다. 실제 하중을 움직이기 전 모터 드라이버의 단자, 전원, 리미트 스위치, 물리적 비상정지 장치를 반드시 검증해야 합니다.

사용 안내
① Arduino IDE에서 동봉된 Crane_R4_BLE.ino를 UNO R4 WiFi에 업로드합니다.
② Android Chrome 또는 iPhone Bluefy에서 HTTPS 주소로 접속합니다.
③ '블루투스 연결' → CRANE-R4-BLE 선택 → 연결합니다.
④ 속도를 설정하고 정회전·역회전 버튼을 길게 누릅니다.
⑤ 최초 온라인 접속 후 브라우저 캐시가 저장되면 오프라인 페이지 열기를 시도할 수 있습니다. 브라우저의 캐시 정책에 따라 달라집니다.
블루투스 연결 자체는 Wi-Fi나 인터넷을 사용하지 않습니다.
